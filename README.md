# IEEE COMST Submissions

Companion code and reproducibility artifacts for manuscripts submitted to
*IEEE Communications Surveys & Tutorials*.

## Contents
- [`power-surge/`](power-surge/) — reproducibility artifact for **"Power Surge: A
  Comprehensive Survey of the Electrical Impact of Artificial Intelligence Inference in
  Modern Data Centers"** (N. Mehta). Regenerates all figures (Fig. 1–10) and the summary
  tables in the paper from primary data. See the folder's README for requirements and usage.
